XAI Playground

A collection of experiments, implementations, and experiments with Explainable AI (XAI) methods for computer vision.

This repository is a personal research playground for testing different explanation techniques across models, datasets, and tasks — with a focus on understanding what different XAI methods actually reveal about visual models.

The goal is not to build a single XAI framework, but to keep a reproducible record of the methods and pipelines I experiment with.

What is explored here?

The repository contains experiments with methods such as:

LIME — Local Interpretable Model-agnostic Explanations
SHAP — SHapley Additive exPlanations
Grad-CAM / Grad-CAM++ — Gradient-based visual explanations
CAM-based methods
TCAV — Testing with Concept Activation Vectors
Concept-based explanations
XAI → Natural Language pipelines
Other XAI methods and techniques as they are explored

Methods may be tested with different architectures, datasets, and downstream tasks.
